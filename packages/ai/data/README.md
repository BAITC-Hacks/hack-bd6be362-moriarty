# 11.txt каталог көшірмесі

`ekt-snapshot.json` пайдаланушы берген `11.txt` ішіндегі JSON блоктарынан импортталды: 1–2 бет, 40 бірегей тауар, `515291` тауарының бір толық detail жауабы. Бұл бүкіл каталог емес; келесі беттер файлда жоқ.

Бағалар, атаулар, артикулдар, суреттер, өнім сілтемелері және raw properties сақталған. `url_api_detail` — бастапқы дерек ретінде ғана сақталады; импорттаушы ол URL-дерді ашпайды. Қосымша каталог немесе синтетикалық тауар араластырылмайды.

`515291`: файлдағы бағасы 64 920 ₸, жалпы қалдығы 23, Алматыда 5. Қалған 39 өнімнің қалдығы белгісіз (`null`). Атауы мен сипаттамада `160А`, `NOMINALNYY_TOK` өрісінде `250 А`: нормалайзер `dataQualityWarnings` береді, бастапқы мәндерді өзгертпейді.

`importedAt` — жергілікті импорт уақыты. API дерегінің алынған/жаңартылған уақыты белгісіз, сондықтан `fetchedAt` ойдан жасалмайды. Жауаптар `source: "file"`, `sourceName: "11.txt"` белгісімен шығады. Бұл деректермен нақты себетті өзгертуге болмайды: live баға/қалдық тексерісі қажет.

Қайта импорттау:

```powershell
npm run import:catalog -- "C:\Users\akk77\OneDrive\Desktop\11.txt"
npm run demo:ai
```

Қайта импорт сәтті валидациядан кейін тек `ekt-snapshot.json` файлын жаңартады. Бастапқы `11.txt` өзгермейді. Мәтіндегі тақырыптар мен нұсқау тәрізді жолдар орындалмайды; тек JSON деректері оқылады.
