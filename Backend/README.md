# EKT Data/Backend — 1-ші адамның тапсырмасы

Node.js 22+ модулі, сыртқы тәуелділіксіз. Тек Data/Backend жұмысы: EKT клиенті, нормализация, іздеу, аналог кандидаттары, спецификация есебі. AI диалогы, файлдан жолдарды шығару, интерфейс және корзина осы модульге кірмейді.

## Іске қосу

```powershell
cd Backend
Copy-Item .env.example .env
node --env-file-if-exists=.env src/server.js
```

Әдепкі адрес: `http://127.0.0.1:8001`. Тест: `node --test`.

`sample` режимі пайдаланушы жіберген екі каталог бетін және 515291 тауардың ықшамдалған detail үлгісін оқиды. Бұл ағымдағы қойма жағдайына кепілдік бермейтін жергілікті snapshot. Жауапта `mode: "sample"`, `source: "cache"` бар. Sample `fetchedAt` — жергілікті файл уақыты; EKT серверінен алынған уақыт белгісіз. Git checkout файл уақытын өзгерте алатындықтан, frontend sample режимін міндетті түрде демо деп көрсетуі керек.

Live режиміне өту үшін `.env` ішіндегі `EKT_MODE=live`, `EKT_API_LOGIN`, `EKT_API_PASSWORD` өрістерін толтырыңыз. Құпия сөз репозиторийге жазылмайды. Клиент `https://ekt.kz/api/products?page=N` арқылы бос бетке дейін оқиды және `/products/detail?id=...` арқылы тауарды толықтырады. Қайталанған бет немесе 1000 бет шегі қатемен тоқтайды. Live байланыс осы жұмыста тексерілген жоқ; тесттер жалған HTTP жауаптарымен орындалады.

## API және интеграция

| Әдіс | URL | Нәтиже |
|---|---|---|
| GET | `/api/products?q=027228` | `{items: [{product, matchType}], fetchedAt, source, mode}` |
| GET | `/api/products/515291` | Нормализацияланған толық тауар |
| GET | `/api/products/515291/analogs` | Техникалық сипаттамалары сәйкес, қалдығы бар кандидаттар және түсіндірме |
| POST | `/api/specifications/match` | Әр жолдың нәтижесі, табылған/табылмаған саны, жалпы сома |

POST денесі:

```json
{"rows":[{"query":"027228","requestedQty":2},{"query":"unknown","requestedQty":1}]}
```

Берілген snapshot үшін бірінші жол: `found`, `availableQty: 23`, `unitPrice: 64920`, `lineTotal: 129840`. Екінші жол: `not_found`, баға мен сома `null`. Жалпы нәтиже: `totalFound: 1`, `totalMissing: 1`, `grandTotal: 129840`.

Әр жолда `inputQuery`, `matchedProduct`, `status`, `analog`, `requestedQty`, `availableQty`, `unitPrice`, `lineTotal` қайтарылады. Күйлер: `found`, `not_found`, `analog_suggested`. `totalMissing` аналог ұсынылған жолдарды да қамтиды; аналог жалпы сомаға кірмейді. Есеп сұралған санға жасалады, қор резервтелмейді және жеткілікті екені автоматты түрде расталмайды. Белгісіз баға/қалдық `null`; есептелмеген сомалар жалпы сомаға қосылмайды.

AI модулі `Catalog.searchProducts(query)`, `Catalog.getProduct(id)`, `Catalog.findAnalogs(product)`, `Catalog.matchSpecification(rows)` әдістерін импорттай алады немесе HTTP қолданады. Frontend үшін бір origin астындағы proxy арқылы қосыңыз. Сервер тек localhost тыңдайды; production жариялау үшін қолжетімділікті шектеу, rate limit және TLS қажет.

## Деректер ережелері

- Дәл артикул/ID/атау алдымен ізделеді. Нәтиже болмаса substring, ол да бос болса Levenshtein іздеуі қолданылады. `02722` сұранысы `027228` тауарын табады.
- Спецификация тек бірегей дәл сәйкестікті `found` деп белгілейді. Fuzzy және екіұшты нәтижелер автоматты таңдалмайды. Live режимінде бірегей substring кандидатының detail жауабы жеткізуші артикулын тексеруге қолданылады.
- Аналог тек белгілі категория, полюстер, ток, кернеу, ажырату қабілеті сәйкес болғанда және қалдық оң болса ұсынылады. Дерек жеткіліксіз болса бос тізім қайтарылады. Бұл инженерлік үйлесімділіктің толық кепілдігі емес.
- 515291 атауында 160А, ал `NOMINALNYY_TOK` қасиетінде 250А бар. Шикі қасиет сақталады, нормализацияланған ток `null`, `warnings: ["nominal_current_conflict"]`. Бұл тауар үшін автоматты аналог жоқ.
- Тізім беттерінде қалдық берілмеген: оны нөл деп көрсетуге болмайды. Сертификат пен сатып алу шарттары берілмесе ойдан қосылмайды.
- Әр тауарда `fetchedAt`, `source` бар. HTTP конвертіндегі уақыт — пайдаланылған деректердің ең ескі уақыты; аралас дерек көзі `cache` деп белгіленеді. Бос каталог үшін уақыт `null` болуы мүмкін.
- Live кэш 60 секунд; кэштен оқу бастапқы уақытты өзгертпейді. API қатесі ескі деректі жаңа деп көрсетпейді, HTTP 502 қайтарылады. Іздеу индексі іске қосылғанда жүктеледі; толық каталогты жаңарту үшін серверді қайта іске қосыңыз. Detail сұрауы жеке тауарды жаңартады.
- Файлдан алынған жолдар жай іздеу мәтіні: орындалатын команда ретінде өңделмейді. Бұл модульде корзина өзгерту әрекеті жоқ.

## Файлдар

`src/client.js` — BasicAuth, timeout, беттеу, кэш; `src/normalize.js` — Product және қайшылықтар; `src/catalog.js` — іздеу және есеп; `src/server.js` — HTTP интеграциясы; `data/` — берілген snapshot; `test/` — деректер және API тесттері.
