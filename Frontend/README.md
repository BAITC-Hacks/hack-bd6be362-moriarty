# EKT Assistant — прототип HackAlem AI

Прототип ассистента для чата ekt.kz построен как локальное FastAPI-приложение: браузер обращается к API с сессионной cookie и CSRF-защитой, API читает каталог из SQLite, а `agent.py` отвечает в детерминированном demo-режиме либо через OpenAI Responses API с инструментами. Сервер, а не модель, владеет каталогом, остатками и корзиной; добавление в корзину возможно только через отдельные prepare/confirm-запросы с одноразовым токеном и повторной проверкой цены и остатка.

## Модули

- `app/main.py` — HTTP-маршруты, сессия, CSRF/CSP и обработка чата.
- `app/agent.py` — demo-ответы и цикл инструментов OpenAI; не меняет корзину напрямую.
- `app/catalog.py` — поиск, технические аналоги, условия покупки и сопутствующие товары.
- `app/store.py` — SQLite-каталог, история сессии, корзина и одноразовые подтверждения.
- `app/uploads.py` — безопасное извлечение текста/изображений из разрешённых вложений.
- `app/import_catalog.py` — валидация и явный импорт каталога в SQLite.
- `app/ekt_source.py` — опциональная разовая загрузка каталога из тестового API ekt.kz.

## Локальный запуск

Нужен Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Для запуска AI-режима задайте `OPENAI_API_KEY` в локальном `.env`; без него остаётся доступен demo-режим. Никогда не добавляйте `.env` в Git.

## Данные каталога

По умолчанию используется синтетический `data/products.json`. Каждая запись содержит `id`, `article`, `name`, `brand`, `category`, `price`, `currency`, `unit`, `specifications`, `stock`, `certificate_url` и `is_demo=true`. `stock` — список складов с полем `quantity`; цены поддерживаются в KZT.

При наличии согласованного тестового доступа можно разово импортировать реальный каталог: задайте `EKT_API_BASE_URL`, `EKT_API_LOGIN` и `EKT_API_PASSWORD` в `.env`, затем выполните `python -m app.import_catalog --source=ekt`. Логин и пароль не публикуются в документации и не используются при чат-запросах. Импорт сохраняет нормализованные товары в ту же SQLite-базу, помечая их `is_demo=false`; ошибка API или смена схемы останавливает импорт с понятной ошибкой.

## Реализовано в кейсе

- поиск товара, карточка, цена, остаток и ссылка на сертификат;
- технически совпадающие аналоги при нулевом остатке;
- условия покупки;
- добавление в корзину только после явного подтверждения с одноразовым токеном и ревалидацией;
- просмотр корзины по ссылке;
- сопутствующие товары и предложение обратиться к менеджеру, когда поиск не помог.

Не реализованы авторизация пользователя и персистентная история между сессиями. Эскалация менеджеру — только явная `mailto:`-заглушка, без CRM и автоматической отправки данных.
