# EKT Assistant — HACKALEM AI прототипі

ekt.kz кейсіне арналған каталог кеңесшісі: тауарларды табу, сипаттама мен сертификатты көрсету, қолжетімді аналог ұсыну және нақты растаудан кейін себетке қосу.

**Барлық 24 тауар, бренд, баға, қалдық, қойма және коммерциялық шарт синтетикалық. Нақты ekt.kz API-іне қосылмаған. Сертификат сілтемесі тек тестілік мәтіндік құжатты ашады; заңды сертификат емес.**

## Жылдам іске қосу

Python 3.11 немесе жаңарақ нұсқасы қажет. Windows-та `start.bat` файлын екі рет басыңыз. Алғашқы іске қосуда тәуелділіктерді жүктеу үшін интернет қажет. Кейін демо режимі интернетсіз жұмыс істейді.

Браузерде **http://127.0.0.1:8000** ашыңыз. Серверді тоқтату: терминалда `Ctrl+C`.

Қолмен, жоба бумасында:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

8000 порты бос болмаса, `--port 8001` деп іске қосып, сәйкес мекенжайды ашыңыз. `index.html` файлын тікелей ашпаңыз: интерфейске сервер қажет.

## Екі режим

**Демо:** әдепкі режим. Ережелерге негізделген каталог іздеуі, аналогтар, сатып алу шарттары, файлдан артикул алу және себет. Бұл режим тілдік модель емес, еркін диалог мүмкіндігі шектеулі.

**ЖИ:** OpenAI Responses API арқылы модель құралдарды шақырады. Агент каталогты оқиды, аналогтарды іздейді және себетке қосу ұсынысын дайындайды. API кілті серверде ғана сақталады.

1. `.env.example` файлын `.env` деп көшіріңіз.
2. Өз API кілтіңізді `.env` ішіндегі `OPENAI_API_KEY=` жолына **жергілікті редакторда** енгізіңіз. Кілтті чатқа, браузер кодына немесе Git-ке салмаңыз.
3. `OPENAI_MODEL=gpt-6-sol` — бастапқы модель. Қолжетімді модель идентификаторын таңдауға болады.
4. Серверді қайта іске қосыңыз.
5. Чаттағы «ЖИ · OpenAI API» режимін таңдап, мәтін/диалог/тіркемені OpenAI-ға жіберу келісімін белгілеңіз.

API қолданылуы бөлек есептелуі мүмкін; Codex ішіндегі модельді таңдау осы қолданбаға API кілтін бермейді. Кілтсіз ЖИ режимі ашылмайды. Қате болса интерфейс себебін жалпы түрде көрсетеді; демоға жасырын ауыспайды.

OpenAI интеграциясы: https://developers.openai.com/api/docs/guides/function-calling

## Дерекқор қайда?

**`data/app.sqlite3`** — SQLite дерекқоры. Бөлек PostgreSQL/MySQL орнату қажет емес. Алғашқы іске қосу кезінде автоматты түрде құрылады; сервер қайта іске қосылғанда деректер сақталады.

- `products`: тауардың ID-і және JSON деректері (артикул, атау, баға, техникалық параметрлер, қоймалар, сертификат сілтемесі).
- `sessions`: кездейсоқ сессия ID-і, CSRF токені, жасалған және соңғы қолданылған уақыт.
- `cart`: сессия, тауар, саны; сессияға тиесілі себет.
- `pending`: растауды күтіп тұрған тауар, сан, сол сәттегі баға, бір реттік токен, жасалған уақыт.
- `history`: соңғы 16 пайдаланушы/ассистент хабарламасы. Тіркеме мазмұны сақталмайды.

Бастапқы каталог: `data/products.json`. Сервер оны бірінші рет импорттайды; кейін JSON өзгерту бар жазбаларды автоматты жаңартпайды. Өзгерістерді жүктеу үшін:

```powershell
.\.venv\Scripts\python.exe -m app.import_catalog data/products.json
```

Импорт ID бойынша қосады/жаңартады, файлда жоқ бұрынғы ID-лерді жоймайды. Тауарлардың баға/қалдық өзгерістері растау сәтінде қайта тексеріледі. Дерекқорды DB Browser for SQLite секілді құралмен ашуға болады; өзгерту алдында серверді тоқтатып, көшірме жасаңыз.

## Архитектура

```text
Браузер (HTML / CSS / JavaScript)
    → FastAPI: сессия, CSRF, валидация
        → Демо өңдегіш немесе OpenAI Responses агенті
            → search_products / get_product / find_analogs
            → get_purchase_terms / get_cart / prepare_cart_add
                → SQLite
    → Бөлек растау әрекеті
        → токен + сессия + мерзім + баға + қалдық тексеруі
            → транзакция арқылы себетке қосу
```

ЖИ-ге себетті нақты өзгертетін құрал берілмейді. Ол тек ұсыныс дайындайды. Өзгеріс сервердің бөлек растау маршруты арқылы орындалады.

Негізгі файлдар:

- `app/main.py` — HTTP маршруттар, сессия мен қауіпсіздік тексерулері.
- `app/store.py` — SQLite, себет, бір реттік растау.
- `app/catalog.py` — іздеу, техникалық аналогтар, тестілік сатып алу шарттары.
- `app/agent.py` — ЖИ құралдары, Responses циклi, демо режимі.
- `app/uploads.py` — тіркемелерді жедел жадта оқу.
- `static/` — қазақша, мобильді экранға бейімделген интерфейс.
- `tests/test_app.py` — интеграциялық және қауіпсіздік сценарийлері.

## API

### JavaScript интеграциясы

Жіберілген EKT агенті `static/app.js` ішіне қазіргі HTML және FastAPI API-іне бейімделіп енгізілді. HTML бұл файлды `defer` арқылы жүктейді; қосымша `ekt-agent.js` қосудың қажеті жоқ.

```javascript
EKTAgent.open();                         // Чатты ашу
EKTAgent.close();                        // Чатты жасыру
await EKTAgent.send('DEMO-002 бар ма?');  // Ағымдағы режиммен сұрау
await EKTAgent.requestAdd('DEMO-002', 2); // Тек растау ұсынысын дайындау
await EKTAgent.showCart();               // Өзекті себет бетін ашу
```

Растау мен бас тарту батырмалары `EKTAgent.confirm()` / `EKTAgent.cancel()` әдістерін қолданады. `confirm()` әдісін тек пайдаланушының нақты растау әрекетінен шақырыңыз. Сессия HttpOnly cookie-де, CSRF токені жедел жадта сақталады. Жаңа хабарлама ескі ұсынысты интерфейстен алып тастайды; қате болғанда сессия мен себет серверден қайта оқылады. Сәтсіз POST автоматты қайталанбайды. Әрекеттер қатар жіберілмейді, хабарлама шегі — сервердегідей 4000 таңба, күту шегі — 70 секунд. Сертификат сілтемелеріне тек HTTP/HTTPS рұқсат етіледі.

Бастапқы үзіндідегі `POST /api/session`, `/api/cart/{session_id}` және `/health` бұл серверде жоқ. Интеграция төмендегі нақты маршруттарды қолданады.

- `GET /api/session` — cookie сессиясы және CSRF токені.
- `GET /api/products?q=DEMO-002` — каталогтан іздеу.
- `GET /api/terms` — төлем, жеткізу және ең аз партия.
- `GET /api/cart` — осы сессияның себеті.
- `POST /api/chat` — multipart: `message`, `mode`, `cloud_consent`, опционалды `file` және `confirmation_token`.
- `POST /api/cart/prepare` — JSON: `product_id`, `quantity`.
- `POST /api/cart/confirm` — JSON: `token`, `accepted: true`.
- `POST /api/cart/cancel` — ұсыныстан бас тарту; себетке әсер етпейді.
- `GET /cart` — сол сессияның нақты өзекті себет беті.

POST сұраулары `X-CSRF-Token` тақырыбын және сессия cookie-ін талап етеді. Схемаларды `/docs` арқылы қарауға болады; POST үшін тақырыпты беру қажет.

## Демонстрация сценарийі

1. «DEMO-002 бар ма?» → 2660 ₸, 14 дана; сипаттамалар және тест сертификаты карточкада.
2. «DEMO-001 бар ма?» → қалдық 0; DEMO-002/003 аналогтары, параметрлік негіздеме.
3. «Төлем және жеткізу шарттары қандай?» → тестілік шарттар, ең аз партия.
4. «DEMO-002 тауарынан 2 дана қос» → ұсыныс. Осы сәтте себет өзгермейді.
5. «Иә, қос» батырмасын басу немесе ұсыныс көрініп тұрғанда дәл осы мәтінді жіберу → себетте 2 дана, 5320 ₸.
6. Себетке сілтемені ашу → сол сессияның себеті.
7. 100 дана сұрау → қалдық шектеуі, себет өзгермейді.

Ұсыныс 10 минут жарамды, бір рет қолданылады, нақты сессия/тауар/сан/бағамен байланысқан. «Иә» сияқты жалпы жауап растау болып саналмайды. Жаңа сұрақ бұрынғы ұсынысты жояды. Дана/метр саны прототипте бүтін санмен беріледі. Бір тауарды бірнеше рет қосқанда жалпы саны қалдықтан аспайды.

## Файлдар

- XLSX: алғашқы 5 парақтың әрқайсысынан 300 жол × 20 бағанға дейін; формулалар орындалмайды, сақталған мәндері оқылады.
- DOCX: мәтін және кестелер.
- PDF: 30 бетке дейінгі мәтіні бар құжат. Скан PDF үшін жергілікті OCR жоқ; JPEG жіберу немесе артикулды мәтінмен енгізу қажет.
- JPEG/PNG: тек ЖИ режимінде модельге сурет ретінде жіберіледі. Демо режимінде шектеу ашық хабарланады.
- Максимум: 5 MB. Құжат мәтінінің алғашқы 20 000 таңбасы өңделеді; қиылғанда хабарланады. XLSX парақ/жол шегі де ескерілуі керек.
- Ескі `.xls` / `.doc` қолдау таппайды: `.xlsx` / `.docx` түрінде қайта сақтаңыз.

Файлдар дискіде немесе база ішінде сақталмайды; өңдеу үшін жедел жадта ұсталады. Диалог тарихы келесі ЖИ сұрауларына қосылады. Құпия және төлем деректерін жүктемеңіз. Карта нөміріне ұқсас мәтін және CVV/PIN үлгілері серверде қабылданбайды; бұл толық DLP жүйесі емес, сурет ішіндегі ақпаратты автоматты жасырмайды.

## Тексеру

JavaScript тексерулері (Node.js 20+; қосымша npm пакеттері қажет емес):

```powershell
node --check static/app.js
node --test tests/agent.test.cjs
```

9 тест DOM/API имитациясымен сессияны, ұсыныс пен растауды, қатар әрекеттерді, жоғалған жауапты қайталамауды, байланыс қалпына келуін, іздеу жауаптарының ретін және сертификат URL-ін тексереді. Бұл тесттер браузердегі визуалды тексеруді алмастырмайды.

Сервер тексерулері:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

29 тест: тауар деректері, сертификат сілтемесі, нөлдік қалдықтағы аналог, шарттар, нақты/қайталанған/ескірген растау, қате сан, ағымдағы себетті ескерген қалдық, өзгерген баға/қалдық, сессия оқшаулауы, CSRF, файлдар және төлем мәтінін сақтамау. OpenAI құралдар циклі жасанды HTTP жауаптармен тексеріледі — тірі API сұрауы емес.

Python 3.14.7 ортасында 29 тест өтті. Бір Starlette/httpx ескіру ескертуі бар, тест нәтижесіне әсер етпейді. Браузерде қосуды растау → себет беті және 390 px мобильді көрініс тексерілді. Тірі API кілті берілмегендіктен модель жауабының сапасы мен кідірісі нақты API-де өлшенген жоқ.

## Нақты дүкенге қосу үшін қалғаны

Бұл — жергілікті хакатон прототипі, өндірістік интеграция емес. Нақты ekt.kz API құжаты, каталог үзіндісі және платформаға қолжетімділік берілген жоқ.

1. `catalog.py` / `store.py` дерек алуын серіктестің каталог және қалдық API адаптеріне ауыстыру; нақты сертификаттар мен сатып алу шарттарын енгізу.
2. Нақты сайттың авторизациясы/сессиясына қосылу; растаудан кейін сайттың себет API-ін шақырып, оның URL-ін қайтару.
3. Серіктестің техникалық маманымен аналог ережелерін тексеру. Қазір барлық берілген техникалық өрістердің толық теңдігі талап етіледі; каталогта көрсетілмеген ерекшеліктер есептелмейді.
4. HTTPS, қауіпсіз cookie, рұқсат етілген host тізімі, аутентификация, сұраныс жиілігі/дене көлемі лимиттері, құжат талдауды оқшаулау, резервтік көшірмелер және сақталу саясатын дайындау.
5. Нақты деректермен дәлдік пен бірнеше секундтық жауап талабын өлшеу. ЖИ бір сұрақта бірнеше құрал шақыруы мүмкін; бірнеше секунд кепілденбейді.

Қазіргі сервер тек localhost үшін конфигурацияланған. Бір процесс/worker режимі ұсынылады. Белсенді емес сессиялар 24 сағаттан кейін келесі API сұрауы/іске қосу кезінде жойылады; cookie мерзімі де 24 сағат. Тұрақты тіркелгі тарихы, менеджерге нақты жіберу, ілеспе тауарлар, төлем және нақты тапсырыс рәсімдеу бұл нұсқада жоқ. Себет қорды резервке қоймайды және төлем деректерін сұрамайды.
